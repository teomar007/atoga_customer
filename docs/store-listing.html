9) ترتيب خطوات النشر في اللوحة

  1. Create app ← الاسم ATOGA MARKET، اللغة الافتراضية العربية، Category: Shopping.
  2. Store listing ← الصق الوصف القصير/الكامل (عربي + فرنسي) + الأصول البصرية.
  3. Store settings ← Privacy policy URL + Account deletion URL.
  4. App content ← Data safety (قسم 6) + Content rating (قسم 7) + App access + Ads=No + Target audience.
  5. Testing ← Production ← Create release ← ارفع `app-release.aab` حسب Play App Signing.
  6. Countries/Regions ← اختر الجزائر (وغيرها إن رغبت).
  7. Review & rollout ← ابدأ النشر.

تنبيه مهم: إن كان حسابك الشخصي (Personal) جديداً، تفرض Google اختباراً مغلقاً مع مختبرين قبل الإنتاج — احسب هذه المدة في الجدولة.
